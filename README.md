# 📄 Universal Resume Parser & Ranking System

A Streamlit-based resume parsing application that works for IT and non-IT jobs.
The app extracts candidate details, matches resumes with job descriptions,
ranks candidates, and exports results in CSV format.

## 🚀 Features
- Upload PDF and DOCX resumes
- Extract email and phone number
- Job description ↔ resume keyword matching
- Resume ranking based on match percentage
- CSV export
- Modern ATS-style UI
- Motivational quote for students

## 🛠️ Tech Stack
- Python
- Streamlit
- pdfplumber
- python-docx

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
